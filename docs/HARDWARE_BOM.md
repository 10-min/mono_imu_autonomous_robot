## 2. 전원 트리 및 예산

```
배터리 12V (또는 3S Li-ion 11.1~12.6V)
 ├── 모터 드라이버 ──▶ 좌/우 JGA25-370 (정지 전류 × 2 대응 필요)
 ├── 벅 컨버터 12V→5V/5A ──▶ Pi 5 (최대 25W, 평시 5~10W)
 │                            └── Camera Module 3 (CSI)
 └── STM32 온보드 LDO 3.3V ──▶ MCU + ICM-20948
```

- 전원 예산을 확정하려면 **모터 정지 전류**와 **배터리 용량/C율**이 필요합니다.
- Pi 5는 5V/5A(27W PD 권장)가 부족하면 무작위 리셋·USB 불안정이 발생할 수 있습니다. 벅 컨버터 정격을 5A 이상으로 잡습니다.
- 모터 전원과 로직 전원은 **공통 GND**로 묶고, 모터 스위칭 노이즈에 대비해 드라이버 근처에 커패시터를 둡니다.

## 3. 인터페이스/핀 매핑 초안

> 아래는 설계 초안입니다. 실제 배선 전 CubeMX와 Pi pinout으로 재확인합니다.

| 신호 | STM32F103RBT6 | Pi 5 | 비고 |
|---|---|---|---|
| UART TX/RX | PA9(TX) / PA10(RX), USART1 | GPIO15(TXD) / GPIO14(RXD), `/dev/serial0` | TX↔RX 교차, 115200 8N1, 3.3V |
| 좌/우 PWM | TIM2 CH1(PA0) / CH2(PA1) | — | 주기 20kHz 권장 |
| 좌 엔코더 A/B | TIM3 CH1(PA6) / CH2(PA7) | — | 11PPR × 4 = 44 count/모터축 회전 |
| 우 엔코더 A/B | TIM4 CH1(PB6) / CH2(PB7) | — | 동일 |
| IMU SPI | — | SPI0 (GPIO 8/9/10/11) | CS 핀은 GPIO로 별도 지정 |
| 카메라 | — | CSI 커넥터 | libcamera |
| 공통 GND | GND | GND | 필수 |

- 주의: IMU는 STM32가 아니라 **Pi에 SPI로 연결**합니다. 만약 STM32로 옮길 경우 SPI1(PA5/PA6/PA7)이 엔코더 TIM3 핀과 충돌하므로 재배선이 필요합니다.
- Pi 5에서 UART 활성화(`enable_uart=1`)와 `/dev/serial0` 확인이 필요합니다.

## 4. 구동/기구 제약 (미측정)

| 항목 | 값 | 영향 |
|---|---|---|
| 바퀴 반지름 `r` | 미측정 | m/s 변환, odom, 최대 속도 계산 |
| 휠베이스 `L` | 미측정 | 회전 반경, `cmd_vel` → 좌/우 속도 변환 |
| 모터 감속비 | 미확인 | 11PPR이 모터축 기준이므로 tick→rad 변환에 필수 |
| 130RPM 기준 | 미확인 | 출력축 기준인지 모터축 기준인지 확인 필요 |
| 로봇 질량 / 마찰 | 미측정 | PID 튜닝, 가감속 제한 |
| 배터리 용량 | 미확인 | 실험 가능 시간 |

- 예시 계산: 감속비 1:1, `r=0.05m`이면 130RPM ≈ 13.6 rad/s → 약 0.68 m/s. 감속비가 다르면 최대 속도도 달라집니다.

## 5. R0-2 게이트에서 확정할 항목

- [ ] JGA25-370 **감속비(기어비)** — 예: 1:34 / 1:56 / 1:90 / 1:130 중 실제 값
- [ ] 130RPM이 **출력축** 사양인지 **모터축** 사양인지
- [ ] 모터 **정지 전류 / 정격 전류** → 드라이버 확정 (TB6612 1.2A/ch 초과 여부)

- [ ] 바퀴 반지름, 휠베이스, 로봇 질량 실측값
- [ ] 카메라 목표 해상도/fps (VIO 권장: 640×480 또는 1280×720 @ 30fps)
- [ ] IMU 목표 ODR (VIO 권장: 200Hz)
- [ ] 섀시/바퀴 조립 상태

## 6. 리스크 및 대체품

| 리스크 | 대응 |
|---|---|
| TB6612FNG가 정지 전류 미달 | DRV8833(1.5A RMS) 또는 DRV8871(3.6A) 검토. 전류 측정 후 결정 |
| Pi 5 전원 부족 | 5V/5A 이상 벅 또는 27W PD 사용, 전선 굵기 확인 |
| Camera Module 3이 `v4l2_camera`에서 인식 안 됨 | libcamera 기반 `camera_ros` 사용 (`P3-1`에 반영됨) |
| 11PPR 엔코더 분해능 부족 | 감속비가 낮으면 카운트 수 부족 → 엔코더 교체 또는 보간 검토 |
| UART 노이즈로 프레임 오염 | CRC16 + 시퀀스 처리 (`P0-6`), 공통 GND/짧은 배선 |

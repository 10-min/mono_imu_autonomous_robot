## 2. 전원 트리 및 예산

```
배터리 12V (또는 3S Li-ion 11.1~12.6V)  ← 배터리 사양 미확정
 ├── L298N (12V 동력) ──▶ 좌/우 JGA25-370
 │     └── L298N 온보드 5V 레귤레이터 또는 외부 5V → 로직(IN/ENA)
 ├── 벅 컨버터 12V→5V/5A ──▶ Pi 5 (최대 25W, 평시 5~10W)
 │                            └── Camera Module 3 (CSI)
 └── STM32 온보드 LDO 3.3V ──▶ MCU + ICM-20948
```

- Pi 5 전원은 **12V → 5V/5A 벅 컨버터**로 확정했습니다. 부족하면 무작위 리셋·USB 불안정이 발생하므로 정격 5A 이상을 유지합니다.
- **L298N 주의**:
  - BJT H-bridge라 전압 강하가 큽니다(전류에 따라 약 2~4V). 12V 공급 시 모터에는 약 8~10V가 걸려 최대 속도가 낮아질 수 있습니다.
  - 방열판 필수. 정지 전류 측정 후 2A/ch를 넘는지 확인합니다.
  - 로직 레벨은 5V TTL입니다. STM32의 3.3V GPIO는 일반적으로 인식되지만(L298 VIH 최소 약 2.3V), 모듈마다 다르므로 **실측 확인 또는 74AHCT125 등 레벨 시프터**를 준비합니다.
  - 저가 모듈은 온보드 5V 점퍼 설정이 다릅니다. 외부 5V 로직을 쓸 경우 **5V 점퍼를 제거**하고 GND를 공통으로 묶습니다.
  - PWM 주기는 1kHz 근처로 시작합니다 (L298는 스위칭이 느려 고주파에서 발열이 큼).
- 모터 전원과 로직 전원은 **공통 GND**로 묶고, 드라이버 근처에 커패시터를 둡니다.

## 3. 인터페이스/핀 매핑 초안

> 아래는 설계 초안입니다. 실제 배선 전 CubeMX와 Pi pinout으로 재확인합니다.

| 신호 | STM32F103RBT6 | Pi 5 | 비고 |
|---|---|---|---|
| UART TX/RX | PA9(TX) / PA10(RX), USART1 | GPIO15(TXD) / GPIO14(RXD), `/dev/serial0` | TX↔RX 교차, 115200 8N1, 3.3V |
| 좌/우 PWM | TIM2 CH1(PA0) / CH2(PA1) | — | 주기 20kHz 권장 |
| 좌 엔코더 A/B | TIM3 CH1(PA6) / CH2(PA7) | — | 11PPR × 4 = 44 count/모터축 회전 |
| 우 엔코더 A/B | TIM4 CH1(PB6) / CH2(PB7) | — | 동일 |
| L298N 좌 (ENA/IN1/IN2) | TIM2 CH1(PA0) / PC0 / PC1 | — | 3.3V GPIO → 5V 로직, 온보드 5V 점퍼 확인 |
| L298N 우 (ENA/IN1/IN2) | TIM2 CH2(PA1) / PC2 / PC3 | — | 동일 |
| IMU SPI | — | SPI0 (GPIO 8/9/10/11) | CS 핀은 GPIO로 별도 지정 |
| 카메라 | — | CSI 커넥터 | libcamera |
| 공통 GND | GND | GND | 필수 (12V/5V/3.3V 전원 모두 공통) |

- 주의: IMU는 STM32가 아니라 **Pi에 SPI로 연결**합니다. 만약 STM32로 옮길 경우 SPI1(PA5/PA6/PA7)이 엔코더 TIM3 핀과 충돌하므로 재배선이 필요합니다.
- Pi 5에서 UART 활성화(`enable_uart=1`)와 `/dev/serial0` 확인이 필요합니다.

## 4. 구동/기구 제약 (미측정)

| 항목 | 값 | 영향 |
|---|---|---|
| 바퀴 반지름 `r` | 미측정 | m/s 변환, odom, 최대 속도 계산 |
| 휠베이스 `L` | 미측정 | 회전 반경, `cmd_vel` → 좌/우 속도 변환 |
| 모터 감속비 | **46.8:1** | 11PPR × 4 × 46.8 = **2059.2 count/바퀴 1회전** |
| 130RPM 기준 | **출력축으로 해석** | 모터축 약 6000RPM ÷ 46.8 ≈ 128RPM과 일치 |
| 로봇 질량 / 마찰 | 미측정 | PID 튜닝, 가감속 제한 |
| 배터리 용량 | 미확인 | 실험 가능 시간 |

- 엔코더 변환 상수: `counts_per_wheel_rev = 11 × 4 × 46.8 = 2059.2`, `rad_per_count = 2π / 2059.2 ≈ 0.003052 rad`
- 최대 속도 추정: 130RPM(출력축) ≈ 13.61 rad/s → `v = 13.61 × r`. `r=0.05m`이면 약 0.68 m/s. 단 L298N 전압 강하로 실제 도달 속도는 더 낮을 수 있습니다.

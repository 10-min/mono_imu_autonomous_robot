## 2. 전원 트리 및 예산

```
배터리 3S Li-po 1800mAh 30C (11.1~12.6V)
 ├── L298N (12V 동력) ──▶ 좌/우 JGA25-370
 │     └── L298N 온보드 5V 레귤레이터 또는 외부 5V → 로직(IN/ENA)
 ├── 벅 컨버터 12V→5V/5A ──▶ Pi 5 (최대 25W, 평시 5~10W) ──▶ UDP 수신 (이더넷)
 ├── STM32 온보드 LDO 3.3V ──▶ MCU + ICM-20948 (SPI1)
 └── 카메라 송신기 ──▶ 별도 전원 (로봇 배터리와 공통 GND 권장)
```

- Pi 5 전원은 **12V → 5V/5A 벅 컨버터**로 확정했습니다. 부족하면 무작위 리셋·USB 불안정이 발생하므로 정격 5A 이상을 유지합니다.
- 예상 가동 시간: 1.8Ah 기준, Pi 측 약 1A + 모터 2×0.5~1A 가정 → 총 2~3A → **약 35~55분**. 정지 전류가 미정이므로 추정치이며 실측 후 갱신합니다.
- 벅 컨버터는 만충 12.6V 입력을 견딜 수 있어야 합니다.
- **L298N 주의**:
  - BJT H-bridge라 전압 강하가 큽니다(전류에 따라 약 2~4V). 12V 공급 시 모터에는 약 8~10V가 걸려 최대 속도가 낮아질 수 있습니다.
  - 방열판 필수. 정지 전류 측정 후 2A/ch를 넘는지 확인합니다.
  - 로직 레벨은 5V TTL입니다. STM32의 3.3V GPIO는 일반적으로 인식되지만(L298 VIH 최소 약 2.3V), 모듈마다 다르므로 **실측 확인 또는 74AHCT125 등 레벨 시프터**를 준비합니다.
  - 저가 모듈은 온보드 5V 점퍼 설정이 다릅니다. 외부 5V 로직을 쓸 경우 **5V 점퍼를 제거**하고 GND를 공통으로 묶습니다.
  - PWM 주기는 1kHz 근처로 시작합니다 (L298는 스위칭이 느려 고주파에서 발열이 큼).
- 모터 전원과 로직 전원은 **공통 GND**로 묶고, 드라이버 근처에 커패시터를 둡니다.

## 3. 인터페이스/핀 매핑 초안

> 아래는 설계 초안입니다. 실제 배선 전 CubeMX와 Pi pinout으로 재확인합니다.

| 신호 | STM32F103RBT6 | Pi 5 / 외부 | 비고 |
|---|---|---|---|
| UART TX/RX | **PA2(TX) / PA3(RX), USART2** | GPIO15(TXD) / GPIO14(RXD), `/dev/serial0` | TX↔RX 교차, **230400** 8N1, 3.3V |
| IMU SPI1 | PA5(SCK) / PA6(MISO) / PA7(MOSI) | — | CS=PA4, DRDY=PC4(인터럽트), 200Hz |
| 좌 엔코더 A/B | **TIM2 CH1(PA0) / CH2(PA1)** | — | 11PPR × 4 = 44 count/모터축 회전 |
| 우 엔코더 A/B | **TIM4 CH1(PB6) / CH2(PB7)** | — | 동일 |
| 좌/우 PWM | **TIM1 CH1(PA8) / CH2(PA9)** | — | L298N 사용으로 **1kHz부터** 시작 |
| L298N 좌 IN1/IN2 | PC0 / PC1 | — | 3.3V GPIO → 5V 로직, 온보드 5V 점퍼 확인 |
| L298N 우 IN1/IN2 | PC2 / PC3 | — | 동일 |
| 카메라 UDP | — | Pi 5 이더넷 | 별도 송신기 → UDP JPEG, 포트/PDU 형식 미정 |
| 공통 GND | GND | GND | 필수 (12V/5V/3.3V/송신기 모두 공통) |

- SPI1(PA5/PA6/PA7)을 IMU에 쓰면 기존 TIM3 엔코더(PA6/PA7)와 충돌하므로, **UART를 USART1→USART2로, PWM을 TIM2→TIM1로, 좌 엔코더를 TIM3→TIM2로 이동**했습니다.
- Pi 5에서 UART 활성화(`enable_uart=1`)와 `/dev/serial0` 확인이 필요합니다.
- IMU는 MCU가 읽어 `IMU_DATA` 프레임(MCU 타임스탬프 포함)으로 Pi에 보냅니다. `stm32_bridge`가 `/imu/data_raw`를 발행합니다.

## 4. 구동/기구 제약 및 유도 상수

| 항목 | 값 | 영향 |
|---|---|---|
| 바퀴 반지름 `r` | **32.5mm (0.0325m)** | m/s 변환, odom, 최대 속도 계산 |
| 휠베이스 `L` | **198mm (0.198m)** | 회전 반경, `cmd_vel` → 좌/우 속도 변환 |
| 모터 감속비 | **46.8:1** | 11PPR × 4 × 46.8 = **2059.2 count/바퀴 1회전** |
| 130RPM 기준 | **출력축으로 해석** | 모터축 약 6000RPM ÷ 46.8 ≈ 128RPM과 일치 |
| 로봇 질량 / 마찰 | 미측정 | PID 튜닝, 가감속 제한 |
| 배터리 용량 | **1800mAh (1.8Ah)** | 실험 가능 시간 약 35~55분 |

### 유도 상수 (파라미터로 사용)

| 상수 | 값 | 계산 |
|---|---|---|
| `counts_per_wheel_rev` | 2059.2 | 11 × 4 × 46.8 |
| `counts_per_meter` | 약 10084.1 | 2059.2 / (2π × 0.0325) |
| `meter_per_count` | 약 0.00009917 m (0.09917mm) | 1 / 10084.1 |
| `rad_per_count` | 약 0.0030513 rad | 2π / 2059.2 |
| `omega_wheel_max` | 약 13.614 rad/s | 130RPM × 2π / 60 |
| `v_max` (이론) | 약 **0.442 m/s** | 13.614 × 0.0325 |
| `v_max` (L298N 강하 반영) | 약 **0.30~0.37 m/s** | 전압 8~10V 기준 |
| `omega_robot_max` (이론) | 약 **4.47 rad/s (256°/s)** | 2 × v_max / 0.198 |

> `cmd_vel` 제한값은 위 이론치 대신 **보수적으로 `linear.x ≤ 0.3 m/s`, `angular.z ≤ 2.5 rad/s`**로 시작해 실측하며 조정합니다 (`P2-3`).
